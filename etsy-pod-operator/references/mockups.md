# Mockups — catalogue and hero rotation

Printify generates every mockup view for every colorway you selected, so the catalogue is
`view × color`. Card labels follow `"<View>, <Color>"` exactly, which is how you select them.

## Views available on the Comfort Colors 1717 (and most unisex tees)

**Product-only**

- `Front` — flat lay, front. Clean, shows the artwork at full size.
- `Back` — flat lay, back. Rarely useful for a front-print listing.
- `Folded` — folded on a surface. Reads as a detail/texture shot.

**On a model** — the numbering is stable per blank, but confirm who each person is by
looking once at the start of a run; Printify does change its library.

At the time of writing on the 1717:

| Tab | Who | Notes |
|---|---|---|
| `Person 1 Front` / `Person 1 Back` | white man, plain backdrop | Printify's default first model |
| `Person 2` | woman, plain backdrop | clean three-quarter |
| `Person 3 Front` / `Back` / `Left Sleeve` / `Context` | Black woman | Context is a styled lifestyle scene |
| `Person 4 Front` / `Back` / `Right Sleeve` / `Context` | Black man | |
| `Person 5 Context` / `Context 2` | white woman, lifestyle scene | warm interior styling |

## Why the hero image matters more than the rest

The Primary image is the thumbnail in Etsy search. It is doing nearly all the work of
earning a click, competing against a grid of forty other shirts. The other six images only
matter once someone has already clicked.

Two consequences:

**Rotate the models.** Printify's ordering puts the same white man first every time, so a
catalogue built on defaults ends up modelled by one person throughout. That reads as
careless to a browsing buyer, and it quietly narrows who pictures themselves wearing the
thing. Spread the hero across the models available — different genders, different skin
tones — over the course of a run.

**Use the flat lay sometimes.** For detailed artwork — engravings, dense collage, fine line
work — a plain `Front` shot at thumbnail size often out-reads a model shot, because the
design gets the whole frame instead of a chest-sized slice of it. Roughly one listing in
three or four is a reasonable share for product-only heroes, weighted toward the designs
with the most detail.

## A workable rotation

Cycle through something like this, adjusting for which colorway leads each design:

1. `Person 3 Front` (Black woman)
2. `Front` (flat)
3. `Person 2` (woman)
4. `Person 5 Context` (white woman, lifestyle)
5. `Person 3 Context` (Black woman, lifestyle)
6. `Front` (flat)
7. `Person 4 Front` (Black man)
8. `Person 1 Front` (white man)

The hero colorway should be the one the design looks strongest on, which is usually the
default variant — Black or True Navy for dark-garment art, Ivory for light.

## The rest of the seven

After the hero:

1. **Hero** — per rotation, on the default colorway
2. **A second model shot** — a different person from the hero, ideally a lifestyle/context
   framing if the hero was a plain backdrop
3-6. **`Front` in each colorway** — this is the colour swatch row; buyers scan it to see
   what they can get
7. **`Folded`** on the default colorway — texture and fabric weight

If a design has fine detail worth inspecting, swap the folded shot for a sleeve view or add
an eighth image rather than dropping a colorway.

## Mechanics

Selection order is listing order and the first pick becomes Primary, so pick the hero first.

Pick cards individually by exact label rather than using Select all — Select all can't
control ordering and behaves unreliably through automation.

Switching view tabs re-renders the grid; wait for it before picking. If a tab or card isn't
found, it's usually still loading — wait and retry.
